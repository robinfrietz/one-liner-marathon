One line: a single comedy joke, up to 280 characters, judged head to head.

> I asked my AI assistant for a joke, and it billed me for the laugh.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Files

- `main.ts` — writes the joke to `/output/entry.txt`, deterministic, no network.
